# Frontend - Sistema de Autenticación 🔐

Aplicación frontend desarrollada en React que consume la API backend para gestionar autenticación de usuarios.

## 🚀 Funcionalidades

- Formulario de login
- Consumo de API (`/auth/login`)
- Manejo de sesión con JWT
- Persistencia de sesión con localStorage
- Obtención de usuario autenticado (`/auth/me`)
- Logout

## 🛠️ Tecnologías utilizadas

- React
- Vite
- JavaScript (ES6+)
- Fetch API
